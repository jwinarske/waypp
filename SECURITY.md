# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | :white_check_mark: |

## Reporting a Vulnerability

Please **do not** open a public GitHub issue for security vulnerabilities.

Report security issues by e-mail to:

**joel.winarske@linux.com**

Include the following in your report:

- A description of the vulnerability and its potential impact
- Steps to reproduce or a proof-of-concept
- Affected version(s) and component(s)

You should receive an acknowledgement within **72 hours** and a resolution
timeline within **7 days**.  If you do not receive a reply, follow up by
opening a GitHub issue labelled `security` (without vulnerability details).

## Scope

This policy covers the `waypp` library and all code under `src/`, `include/`,
and `examples/` in this repository.  Bundled third-party code under
`third_party/` should be reported upstream to the respective projects.
